# 🌸 Iris KNN Classification Model

This project is part of a Machine Learning Bootcamp assignment aimed at implementing an end-to-end ML pipeline using the classic Iris dataset. The pipeline covers data ingestion from MySQL, exploratory data analysis (EDA), K-Nearest Neighbors (KNN) model training, and deployment using Streamlit.

---

## 🚀 Project Objective

To build and deploy a machine learning model that classifies iris flower species based on sepal and petal measurements using K-Nearest Neighbors (KNN). The project demonstrates the full ML lifecycle, from data handling to interactive deployment.

---

## 🧰 Technologies Used

- **Python**
- **MySQL** – data storage
- **SQLAlchemy / PyMySQL** – database connection
- **Pandas, NumPy** – data manipulation
- **Seaborn, Matplotlib** – visualization
- **Scikit-learn** – ML model (KNN)
- **Streamlit** – app deployment
- **Git & GitHub** – version control

---

## 📊 Features

- Data pulled from a MySQL database
- Cleaned and preprocessed Iris dataset
- Exploratory Data Analysis (EDA) with visual insights
- KNN classifier with accuracy metrics
- Streamlit web app to interactively test predictions
- End-to-end reproducibility
